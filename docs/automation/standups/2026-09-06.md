## Lessons (recorded here because `loops/state/` is write-scope-denied)

- **A cross-project check beats a within-project one.** Three standups classified the missed-run gaps from tradeclaw evidence alone and got the cause wrong. One glob across all eight projects' logs settled it in a single call. When a failure looks like it belongs to your component, check whether the neighbours have it too before naming it yours.
- **Absence of a log is stronger evidence than absence of a commit.** The launcher writes a log when it *starts*, so a missing log proves the run never began — a distinction git history cannot make. This is the artifact that separates "never fired" from "fired and died".
- **A schedule that fires off-slot is telling you something.** The `0310 / 0606 / 0724 / 1634` stamp spread was visible for weeks and read as noise. It was the catch-up signature the whole time.
- **A pipeline's exit code is not the command's exit code.** `cmd | tail -20` reported exit 0 while `node` failed with `MODULE_NOT_FOUND`. A green exit through a pipe means the *last* stage succeeded. Check the output, not the status.
