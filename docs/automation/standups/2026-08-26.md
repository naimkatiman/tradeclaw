## Lessons / Escalations (second run)

- **LESSON (new, load-bearing — a bad containment test nearly retracted a true finding):** `git rev-list --all --objects -- <path> | grep <blob>` is **not** a valid "does this content exist in a ref" test. The authoritative tests are `git rev-parse <ref>:<path>` per candidate ref, `git log --all --find-object=<blob>`, and `git log --all --raw --abbrev=40 -- <path>`.
