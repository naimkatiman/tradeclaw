## Lessons

- **A structural fix is only verified by the next occurrence of the same failure.** The write-before-sync change looked like bookkeeping on 10-09. On the identical `Reached max turns (50)` error it converted total loss into a passing gate. The evidence is the pair 10-07/10-09, not the reasoning.
- **A fix that works can hide the next layer.** `GATE PASS` on 10-09 is a true statement about a run whose output never left the machine. Any gate that checks one surface will certify runs that fail on a surface it does not check.
- **Naming a failure class does not slow it down.** The silent-slot class was first described on 10-09 and recurred on 10-10 and 10-11. Description is not mitigation; only the alarm in NEXT item 2 would be.
- **A five-line log cannot support a causal claim.** The absence of `push` in it is absence of transcript, not absence of a push. Leave the cause open.
