## Lessons (durable)

1. **A denial from one tool is not a capability exclusion.** Bash is sandboxed to the session's working directories; `Read` and `Grep` are not. Test each route before escalating "we cannot read X" — an escalation retires an instrument, and a wrong one retires a working instrument permanently, because no later run re-tests what the ledger says is gone.
2. **Prefer a launcher's own roll-up over reconstruction from filenames.** `weekly-all-<stamp>.log` states the batch walk directly. Two runs spent effort inferring from filename stamps what one readable file asserts.
3. **Absence of a signal and absence of a signal *channel* are different findings.** There is no `daily-all-*.log`, so a daily batch window cannot be observed at all. Naming that limit is more useful than a guard that silently fails on half the modes it claims to cover.
4. **Re-check the sha a green check ran against, not just its colour.** Main's four workflows are all `success`, but two of them last ran on `main~1`. "Green at `<sha>`" and "green somewhere in this branch's history" are different claims.
