## Lessons from this run (the state-file append is attempted once below. If it is refused, this section is the record)

1. **Write span expectations per hour, not per day.** The FX week reopens at about 23:00Z Sunday, so a Sunday (01:00Z, 01:00Z] span carries FX rows in its last two hours. "Crypto-only" was only true until then.
2. **Force-expiry also grades gate-blocked rows.** The null-aged predicate excludes them, so to count the Friday fallback you must count gate-blocked rows too (AMZNUSD and AUDUSD on 11-13).
3. **A flat D1 lane's active return is its frozen strategy return minus the benchmark's.** So every daily change in it is a benchmark move. It moved +2.31% → −0.23% in one day with no trade. Never report a day's active-return change as a strategy result.
