## Lessons from this run (the state-file append was attempted once and refused as a sensitive file, as on every run since 10-09, so this section is the record)

1. **An "only D1 rows" claim about the null-aged predicate depends on the weekday.** FX rows emitted in the last hour before the Friday close carry a null 24h outcome across the weekend. A Sunday or Monday probe will see them, and a Saturday probe of weekday rows will not. Scope the check to rows whose 24h window does not cross the FX close, or name the exception up front.
2. **The ledger's snapshot array is `recentSnapshots`, not `snapshots`.** A probe that reads `snapshots` gets 0 entries and a vacuous "0 chain breaks". Read `integrity.status` and `verifiedRows` as the linkage answer (same family as the alpha-ledger field-path lesson).
3. **The Bash filter rejects heredoc JS mixing braces and quotes, and PowerShell refuses `| node -`.** Brace-free `node -e` one-liners (`Promise.all(...).then(...)`) pass. Write probes that way from the start, to save turns against the 50-turn cap.
