## Lessons / Escalations

*(The loop state file at `loops/state/tradeclaw.STATE.md` is machine-record-only and write-blocked as a sensitive path; lessons are recorded here per the established pattern.)*

- **LESSON (new, and the largest single miss in this loop's history):** a phrase repeated in a status report for 43 consecutive days was never once tested. *"Feature to main owner-gated (no PR)"* was a guess that hardened into a fact through repetition. One command — `gh pr list --state all --head <branch>` — falsified it. **A recurring line in your own output is the least-audited claim you carry, precisely because it stops looking like a claim.**
- **LESSON (new, method):** `git merge-tree --write-tree` answers *"would this merge?"* exactly, with zero worktree mutation. This loop declined to open a PR for five weeks partly on an unstated assumption that the merge would be catastrophic. It conflicts in **five files**. **Measure the merge; never estimate it.** Same family as 08-26's *exhaust the log-diff before demanding a live retry*.
- **LESSON (new):** `git status` untracked counts are **mode-dependent**. `-unormal` collapses directories to one row (38); `-uall` expands them (60). Two standups reporting different numbers meant nothing changed. **Pin the flag when a count is going into a report.**
- **LESSON (new, self-correction):** *"non-docs commits ahead of main"* is not the same as *"stranded product work."* Ten of the eleven were the 08-05 regime lane, and `regime-expectancy-study.ts` is byte-identical on `main`. **Ahead-ness is about commit topology; shipped-ness is about content.** Third variant of the same error family — after 08-24's path-vs-content and 08-26's imports-are-not-dates.
- **LESSON (new):** the gate returns PASS on a run that neither pushed nor wrote its trailer. **A green gate attests that an artifact exists on an allowed branch — nothing about whether the run completed.** Three of the last four runs ended incomplete with PASS recorded for all of them.
- **ESCALATION (new, rank 1 — displaces `docs/ai-improvement/`):** the loop's output lane is dead. 28 standups, 43 days, unreachable from `main`, because the branch's only PR merged on 2026-07-15 and none was opened since. Every future run compounds it. The standup-only PR is conflict-free and can be opened today.
- **ESCALATION (carried, now rank 2):** `docs/ai-improvement/` — **+2,462 / −179**, `implementation-log.md` +2,211 lines, blob `175468a8` in no commit and no stash.
- **ESCALATION (carried):** `docker-publish.yml:17` `scripts/**` — a README-media `.ps1` triggers a 30-minute multi-arch GHCR publish. Publish job red 4 days, un-retried.
- **ESCALATION (carried):** `STATE.yaml` uncommitted from a 77-behind base still deletes `TC-250`…`TC-254`.
- **ESCALATION (pattern, upgraded):** scheduler and completion disruptions now number **five in fourteen days** — the 08-25 run that never happened, and four truncated or unpushed finishes (08-22, 08-24, and both 08-26 runs). Not incidents.
