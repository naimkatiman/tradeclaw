## Lessons from this run (the state-file append was attempted once and refused as a sensitive file, as on every run since 10-09, so this section is the record)

1. **Read the resolver before naming a cause for a placeholder outcome.** The 11-08 weekend inference ("no outcome until FX reopens") had the wrong mechanism. The `source: force-expired` field and a 2×-horizon age rule explain the timestamps to the minute. When an outcome lands near a market event, check `source` before attributing it to the event.
2. **The 24 h `git log` window drops the prior run's first commit when this run reconciles a few minutes later in the slot.** Use `--since=<prior run start>` as the primary DONE query and treat the 24 h query as a cross-check (refines 11-07 lesson 2).
3. **`main`'s `Weekly GitHub Pulse` runs about 09:16Z to 09:29Z Monday, eight hours after this loop's 01:30Z slot.** Never set a same-day check for it. Set it for the next day.
4. **Inline probes: PowerShell rejects `;` in `node -e` as multiple operations and caps commands near 1,000 bytes, and the Bash wrapper rejected a quoted heredoc.** Bash `node -e "…"` with comma expressions and expression-bodied arrows ran every probe on the first try. Use Edit, not a heredoc, to append to the standup.
