The 09-01 standup's headline claim was: *"the 2026-08-31 run is the first in this loop's history to produce NO artifact in any state (not on disk, in no commit on any ref, not even untracked)."*

Six dates, eight runs. The gate caught every one of these correctly.

**Class B — ran, gated PASS, artifact on disk but never committed.** The 08-27 class. Seven PASS verdicts hid it. The gate is blind here because it only tests the filesystem.

**Class C — the launcher never fired; no run record exists.** `2026-08-14` through `2026-08-19` (six consecutive dates — records jump `08-13_0930` → `08-20_0606`), `2026-08-25` (records jump `08-24_0930` → `08-26_0614`), and now `2026-09-02`. Eight dates.

Eight lost days are currently indistinguishable from eight days that were never scheduled. That is a larger hole than the Class B blind spot that has been carried since 08-29, because Class B at least leaves a file on disk to find.
