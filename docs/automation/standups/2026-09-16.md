## Calmar is now settled as arithmetic, not judgment

The 09-12 standup flagged its own Calmar finding as probable annualisation noise and the 09-15 run upheld the caveat. Neither could state the mechanism. It is measured now: the formula was reverse-engineered from the payload and **confirmed on two independent days**.

```
Calmar = CAGR / maxDrawdown,  where CAGR = (1 + netReturn)^(365 / calendarDays) − 1
```

Check on 09-15: `(1.081041939309)^(365/36) − 1 = 1.20355` → `1.20355 / 0.044742174226 = 26.899` vs published `26.900001943385192`. Check today: `(1.037735771907)^(365/37) − 1 = 0.44111` → `0.44111 / 0.059789146324 = 7.3777` vs published `7.377585866383567`. Reproduces to four significant figures both times (the residual is my log/exp precision, not a discrepancy).

At 37 days the annualisation exponent is **9.86**. Today's move decomposes cleanly:

| leg | Calmar | driver |
|---|---|---|
| 09-15 published | 26.900 | — |
| return + exponent only (old denominator) | 9.859 | net return 8.1042 % → 3.7736 %, amplified ~10× |
| both legs (new denominator) | 7.378 | max drawdown 4.4742 % → 5.9789 % |

A **−72.6 % move in one day**, with roughly two-thirds from the amplified numerator and one-third from the denominator. Both legs of Calmar are unstable at n=37. The caveat is no longer inferred — it is arithmetic, and it closes.

**Reporting rule this establishes:** do not publish `strategyCalmar` as a trend before the annualisation exponent approaches 1. Report the drawdown pair and the return pair, which are raw.
