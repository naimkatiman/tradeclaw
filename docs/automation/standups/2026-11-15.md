## Lessons from this run (the state-file append was attempted once and refused as a sensitive file, as on every run since 10-09, so this section is the record)

1. **The null-aged check is D1-only on weekdays only.** From Saturday to Monday, Friday's last FX batch sits null in the 24–48 h band until the 2× horizon fallback fires. Before you call a weekend non-D1 match a defect, check whether its timestamp is Friday's last batch.
2. **Weekend spans are not empty.** Crypto scans run every day. Write span expectations per asset class, not per market calendar.
3. **A gate PASS does not mean the run succeeded.** DrSaid's 11-14 knowledge run hit max turns, exited 1, and still logged `GATE PASS` because its artifact had already passed `minLines`. Read `claude exit` before trusting a gate verdict, in any project.
4. **Write scratch probes to `%TEMP%`.** It keeps the repo's gitignored directory clean when the run cannot delete files.
