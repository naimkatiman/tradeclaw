## Lessons from this run (the state-file append was attempted once and refused as a sensitive file, as on every run since 10-09, so this section is the record)

1. **H4 rows publish after their candle closes, but carry the candle-open timestamp.** `SIG-ETHUSD-H4-SELL-MWE7MYO0` is stamped 11-13T00:00Z and was published at 04:47Z, 288 minutes later. A 01:35Z read therefore always undercounts the span that just closed. Treat a span as final only after about 5 h, which in practice means its second daily read.
2. **Check the batch timestamp before naming what a provisional count is missing.** 11-13 assumed the 01:00Z closing batch was not yet visible. No row carries that timestamp. The missing row was an H4 row whose `publishedAt` came later.
3. **A window-edge drop is not a grading change.** The null-aged count fell from 3 to 2 because the 800-row window slid past 11-05T00:00Z. Before reading a count change as a data change, decode the oldest row in the window.
