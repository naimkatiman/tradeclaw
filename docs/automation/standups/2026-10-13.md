The consequence is that a detached-HEAD run clears branch safety entirely — and this repo has an instance on record: the ledger row `2026-07-14_2313` is labelled "Gate-only revalidation after the detached-HEAD fix."

**Did not touch `gate.ps1` or `tradeclaw.json`.** Both are shared loop infrastructure outside this repository, and a wrong `branchPattern` would begin failing runs rather than protecting them. Escalated with the exact edit instead.
