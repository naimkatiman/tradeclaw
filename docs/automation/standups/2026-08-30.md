## Lessons (durable)

- **A conclusion drawn from two consecutive CI failures is not a determinism proof.** The 08-29 run
  called arm64 a deterministic blocker on n=2; run 3 passed clean. Two failures with *different*
  signatures (SIGILL vs a silent 28-minute stall) is evidence of flakiness, not of a fixed fault.
- **Playwright retries inside one run are not independent trials.** They reuse the same dev-server
  process, so 3/3 failures in a single run says nothing about determinism across runs.
- **When CI red lands on a commit that touched no code, probe production before escalating.** A
  single `git grep` (one JSX literal) plus one live GET (phrase renders once) reclassified a
  "duplicate copy regression" as a CI-only double-mount in two steps.
- **`git status --porcelain` collapses untracked directories; `-uall` does not.** A 64→42 "drop" was
  purely a reporting artifact. Always count untracked with `-uall` before claiming work vanished.
